3.1Architecture and technology

From the founder's browser to the models and the data

Three tiers. The browser talks only to the Next.js app. Its server forwards each call to the FastAPI service with the API's key, which never reaches a browser.

Guarded twice. Every request passes the guard before a route; every piece of text a model reads from the founder, the web or a document passes the prompt guardrails.

Degrades gracefully. Without a database, sessions live in memory; without a key, its research, look-up or tracing is skipped and the rest still runs.
