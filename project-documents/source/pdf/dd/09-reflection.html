The choiceWhat it buysWhat it costs
One specialist node, four rolesNo four near-identical files; the agents differ only in point of viewPer-agent behaviour must be said in role text, not code
One revision, one critique roundCheap, and a run always endsLess iteration; both are settings, so more rounds need no code
No critique for a lone reportFewer calls, lower latencyNothing to cross-check it against anyway
Two conflicts each, settled in one callDecisions that agree, for one call instead of one eachMinor clashes beyond the first two go unresolved
Failures non-fatal where possibleOne failed call does not sink a two-minute runA run can end with a named gap or an unreviewed report
Word targets: 250 a report, 500 the strategyEvery later call is faster and cheaperLess detail; the model treats them as targets
Reviews and critiques in parallelLower latency, same calls and tokensBursts of up to four calls reach a rate limit sooner

9.2Reflections

Limitations, and what would come next

Close the type-safety gaps

Enforce the ranges and counts that now live in descriptions (review and judge scores, conflicts, searches); retry a reply that fails validation once, then handle it like any unusable reply; validate a research profile's raw JSON with a model. Each small, each testable with the fake model (6.3).

More than one worker

The Monitor's statistics and the rate limits live in the API's process, so the app runs one worker. Sessions, reports and the history are already shared in PostgreSQL; a shared store for the limits would let replicas share them too.

Accounts

Access is one API key, held by the app's server. A product with several founders would add user accounts and sign-in, with sessions and reports owned by a user; TLS and a domain belong to the reverse proxy in front.

The model's limits

At minimal reasoning, gpt-5-mini writes plausible numbers without reasoning over them, which is why the money is worked out in code and checked. Higher efforts help at the cost of time; the sliders and the experiments make that trade measurable.

Tools in the specialists' hands

Look-ups are planned by the Chief of Staff (decision D1). Letting a specialist call tools in a ReAct loop is the natural next option, bounded like everything else, once its cost is measured.

Where the project stands

Steps 0 to 30 are marked Done in the plan; Steps 31 to 35 (MCP look-ups, the live graph, the document page, exchange rates, Langfuse) are marked Built: built and checked live, before being marked Done. Web searches on Azure go to Bing, outside Azure's compliance boundary, which the README notes.

9.4Reflections · reference

Glossary

  • Chief of StaffThe manager agent: plans, reviews, settles conflicts, writes the strategy.
  • SpecialistOne of four agents with an area: marketing, finance, technical, risk.
  • LangGraphThe library that runs the agents as a state machine of nodes and edges.
  • RouterA function that reads the state and names the next step or steps.
  • CheckpointerSaves a session's state after each step, so it can be resumed.
  • SessionA first request and its follow-ups, sharing one state.
  • ReducerThe rule that merges what parallel steps write to one field.
  • Follow-upA later request in a session; only the agents it concerns rerun.
  • Deep researchA cited web report per specialist's area, and competitor profiles.
  • Plan–Act–CheckPlan the work, do it, check it, send back what falls short.
  • Cross-critiqueSpecialists flag where another's report contradicts their own.
  • Structured outputA model reply constrained to a JSON Schema, parsed into a typed object.
  • PydanticThe library that defines those types and validates data against them.
  • Reasoning effortHow long gpt-5-mini thinks before answering: minimal to high.
  • GuardrailsFences and rules that keep outside text from steering the agents.
  • Prompt injectionText that tries to give a model instructions it should not follow.
  • LLM judgeA separate model call that scores the strategy against its brief.
  • Live graphThe graph LangGraph runs, drawn with Mermaid and lit up step by step.
  • MCPModel Context Protocol: a standard way to give models tools and data.
  • FREDThe St. Louis Fed's database of official economic series.
  • BM25A ranking of passages by how well their words match a query.
  • SSEServer-sent events: a response that streams messages as they happen.
  • Trace, scoreIn Langfuse: a request's record of model calls, and a judgement on it.
  • DraftA change to a document, shown before it is accepted and saved.
  • NPV, IRR, paybackInvestment returns, worked out in code from the projections.
  • PrometheusA monitoring system that scrapes the API's /metrics.
  • MonitorThe How it works tab that shows what the API has done.
