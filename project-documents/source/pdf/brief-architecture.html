2System architecture

From the founder's browser to the models and the data

Browser to API: the browser only talks to the Next.js app, whose server adds the API key. Every request passes the guard before a route; every model prompt passes the guardrails. Optional: without a database, sessions live in memory; without keys, research, look-ups and tracing are skipped.

3The agent workflow

Plan, act, check: a LangGraph state machine with bounded loops

11 nodes, 40 edges, 37 of them routes the state chooses (graph.py). Hierarchical: the Chief of Staff plans, reviews, settles conflicts and writes the strategy. Bounded: one revision after review, one critique round; every model call has a timeout and retries.
